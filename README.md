# Hospital Data Management System

A simple console-based Hospital Data Management System developed using C# and SQL Server concepts.

## Features

- Patient data management
- Basic hospital record operations
- Database connectivity using C#
- Console-based user interaction
- Simple access validation flow

## Tech Stack

- C#
- .NET
- SQL Server
- ADO.NET

## Project Structure

```text
HDMS_App/
├── Program.cs
├── Models/
├── Services/
└── README.md
```

## Configuration

Update the database configuration before running:

```text
datasource = "YOUR_SERVER_NAME";
database = "YOUR_DATABASE_NAME";
```

## How to run

- dotnet restore
- dotnet build
- dotnet run

## Notes

This project is intended for learning and portfolio demonstration. Local machine details and sensitive access codes are removed.
